Then: Govern & manage → Approvals, where KSA's owner approves each preference.

Everything is set up from the admin console's Create Memory Setup wizard. The wizard recognises a consumer-only agent by itself when every ticked preference belongs to another team, and skips the steps it doesn't need. The approval then happens in one place, preference by preference.
