The idea

Memory belongs to an agent. Sharing is a decision, not a default.

1 · Own

Each agent declares the preferences it keeps, and classifies each one's sensitivity.

2 · Share by approval

Other agents request specific preferences, to read or also to write. The owner approves each one.

3 · Enforce at runtime

The platform returns only approved preferences and blocks anything the rules forbid.

Three words carry the whole model: own, share, enforce. An agent owns what it declares. Nothing is shared until the owner says yes, preference by preference. And the rules are not left to each agent's prompt; the platform checks every read and every write.
