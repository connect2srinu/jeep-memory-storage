This answers the brand question from the business. The customer tells Cooklist; the value is written into KSA's own schema, checked against KSA's rules, and KSA reads it back next time. There is never a second copy to fall out of sync. The guardrails keep it narrow: specific approved preferences, customer-stated values only, no health data, and every such write is marked in the logs.
