Enforced on every call

The platform checks. The prompt doesn't have to.

One customer only

No agent can read another customer's memory.

Approved only

Unapproved preferences never reach the agent.

Content screened

Restricted content blocked; sensitive must be stated.

Purpose limited

An agent's declared purpose must be allowed by the schema.

Retention

Expired values are swept; customers can ask to forget.

Every decision logged

Saved, refused or declined, with sensitive values masked.

These checks sit in the platform, not in each agent. That matters because the agent's model decides what to save, and models make mistakes. Whatever the model tries, the platform only returns approved preferences, refuses restricted content, and logs every decision so it can be audited.
