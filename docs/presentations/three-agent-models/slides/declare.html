What an agent declares

Two kinds of preference

Canonical

Fixed, typed fields in a governed schema. The model can fill them but never invent new ones.

ksa.organic_brand = "Simple Truth"

Can be shared with other agents, per preference.

Dynamic

Free-text facts, but only inside topics the owner approved. Anything outside them is refused.

topic "shopping": "big shop on Sunday mornings"

Stays with its domain; each topic has its own sensitivity.

Canonical preferences are the backbone: a fixed list of typed fields, like organic brand or dietary restriction. The agent's model decides which field a statement belongs to, but it can't add fields. Dynamic memory catches useful facts that don't fit a field, and only within approved topics such as shopping or fulfillment. A consumer-only agent declares neither.
